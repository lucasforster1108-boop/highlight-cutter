# highlight-cutter

## 先说人话：这工具到底干嘛的

很多成人视频动不动就一两个小时，可真正激烈的其实只有几段。这个工具就是先帮你把那几段找出来、剪出来；需要的话，还能拼成一个精华版。这样你就不用拖着进度条来回快进，自己慢慢找了。

它找最激烈的几段，靠两个线索（二选一）：

- **视频带了 funscript，就看这份文件。** funscript 说白了，就是给可遥控电动飞机杯用的动作说明书：视频播到第几秒，它该怎么动、动多大劲，都写在里面。这个工具照着说明书找，哪一段动作最密、最猛，就先剪哪一段。
- **没有 funscript，就听声音。** 它把整条音轨听一遍，挑声音最大的几段。很多片子里，最响的地方往往就是最激烈的地方。

全程都在你自己的电脑上跑，视频不会上传到任何地方，也不用账号和 API key。

## 安装

需要 Python 3 和 ffmpeg（带 ffprobe）在 PATH 里。就这些——脚本只用 Python 标准库。

```bash
# Debian / Ubuntu
sudo apt install ffmpeg
# macOS
brew install ffmpeg
# Windows
winget install ffmpeg
```

## 用法

```bash
# 自动模式：有 funscript 用脚本，没有就用音频
python3 cut.py movie.mp4

# 强制模式，取前 5 段，每段前后各留 5 秒
python3 cut.py movie.mp4 --mode script --top 5 --pad 5

# 顺带把片段拼成一个精华合集
python3 cut.py movie.mp4 --concat -o highlights/
```

输出在 `<视频名>_highlights/`（或 `-o` 指定的目录）：

- `movie_clip01_123s.mp4`……——切出来的片段
- `movie_highlights.mp4`——只有加 `--concat` 才有，全部片段拼成一个
- `clips.json`——每段的起止、时长、分数、来源模式，之后想重切或二次处理不用再跑一遍检测

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--script` | 与视频同名 | funscript 不在视频旁边时，手动指定路径 |
| `--mode` | `auto` | `auto` / `script` / `audio`。auto = 找得到 `.funscript` 就用脚本，否则用音频 |
| `--top` | 5 | 取几段精华 |
| `--pad` | 5 | 每段前后各扩展几秒 |
| `--merge-gap` | 30 | 两段间距小于这个秒数就合并成一段 |
| `--concat` | 关 | 额外把片段拼成一个合集文件 |
| `-o` | `<视频名>_highlights` | 输出目录 |

## 打分原理

两种模式都是拿 10 秒窗口在全片上每秒滑一步。脚本模式的分数 = 窗口内位置变化总量 + 每个动作的加分；音频模式 = 窗口内 RMS 音量之和。然后贪心地取最强的窗口，忽略它 `--merge-gap` 秒内的一切，重复到取满 `--top` 段；扩展后挨得太近的段再合并。

切片段用的是**重编码**（libx264 + AAC），不是流复制。这是故意的：流复制只能切在关键帧上，你的「精华」可能提前好几秒、从上一个场景中间开始。重编码能切在分数说的位置，一刀不差。代价就是慢。

## 局限性

- **激烈不等于好看。** 工具找的是动作最密或声音最响的段落。有时那就是正戏，有时只是吵架或者摄像机掉了。它能把两小时缩到十分钟，最后拍板的还是你。
- **分数是相对本片而言的。** 一部整体很安静的片子照样会给你 top 5，那只是它最不冷清的几段。别迷信默认参数，按片调 `--top` 和 `--merge-gap`：对白多的片用脚本模式更靠谱，音乐主导的片能把音频模式骗得团团转。
- **重编码很慢。** 两小时 1080p 的源片切起来要等一阵。跑上之后去泡杯茶。
- 音频模式需要音轨（听着像废话，但真有无声的录屏，它会直接报错，而不是瞎猜一段给你）。

测试素材全部是合成的（ffmpeg 测试图案 + 正弦音爆，没有任何真实视频）。`tests/run_tests.py` 验证两种模式都能找到预埋的三处爆发段、片段文件与 `clips.json` 一致、`--concat` 能出合集。记录见 `tests/RESULTS.md`。
